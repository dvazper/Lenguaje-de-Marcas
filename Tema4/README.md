# Prácticas de XML - Lenguaje de marcas

Este proyecto incluye varios ejercicios y ejemplos que he ido haciendo para aprender a manejar XML y cosas relacionadas como DTD, XSLT, JSON o el uso de APIs con JavaScript.

## 📁 Ejercicios XML (estructura y validación)

| Ejercicio | Descripción |
|-----------|-------------|
| Ex1a - Tema4/XML-Exercises/Ex1a.xml | Pruebas básicas con estructuras XML simples |
| Ex2         | Ejemplo con noticias en XML y validación por DTD |
| Ex3         | Estructura de empleados (original con errores y corregido) |
| Ex4         | Ejemplo de correo electrónico formateado en XML |
| Ex5a / Ex5b | Catálogo de CDs con DTD y validación, versiones diferentes |
| Ex6         | Ejemplo de una carta escrita en XML |
| Ex7         | Preguntas y respuestas sobre teoría de XML |

## 🌐 Ejercicios con XML y JavaScript (DOM + AJAX)

| Archivo HTML | Descripción |
|--------------|-------------|
| ejercicio1.html | Lectura y visualización de libros desde `books.xml` usando DOM |
| ejercicio2.html | Consulta y listado de CDs desde `cd_catalog.xml` con XMLHttpRequest |
| ejercicio3.html | Generación dinámica de tabla desde XML |

## 📦 Archivos extra utilizados

- `books.xml` — listado de libros con título, autor y más
- `cd_catalog.xml` — catálogo de CDs de música con artista, año, etc.

## 📌 Cosas que he tocado

- Leer XML desde JS (DOM y AJAX)
- Crear estructuras bien formadas
- Validar con DTD (tanto interno como externo)
- Hacer pruebas de errores comunes
- Convertir datos XML en algo visual con HTML

---

## 🔧 Cómo probar esto

1. Abre los `.html` en el navegador (mejor con servidor local si estás usando fetch/XHR).
2. Asegúrate de que los archivos XML estén en la carpeta `datos/` (está todo organizado ya).
3. Si quieres, edita los XML para probar qué pasa con otros datos.
