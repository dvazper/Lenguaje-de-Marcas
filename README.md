# LLMM - Lenguajes de Marcas

Este repositorio recoge todo el contenido trabajado durante el módulo de Lenguajes de Marcas, parte del ciclo de Desarrollo de Aplicaciones Web (DAW). Aquí se incluyen prácticas, apuntes y proyectos realizados a lo largo del curso.

---

## 📌 ¿De qué va este módulo?

El módulo de Lenguajes de Marcas es una de las bases más importantes para quienes se están formando como desarrolladores web. A través de él se aprende a estructurar correctamente contenido web usando distintos lenguajes como HTML, CSS, XML y tecnologías complementarias como JavaScript.

El objetivo es entender cómo funcionan los lenguajes que forman la base visual y estructural de cualquier sitio web moderno.

---
