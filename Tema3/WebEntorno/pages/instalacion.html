Guía de instalación de Visual Studio Community

Accede primero a la web oficial desde aquí:

Página oficial de Visual Studio

Haz clic en descargar y ejecuta el archivo que se haya bajado.

Cuando se te pida permiso como administrador, acepta y aparecerá una ventana como esta:

El instalador comenzará a cargarse, así que ten paciencia.

Selecciona la opción de desarrollo web con ASP.NET y pulsa instalar.

Solo queda esperar a que se complete la instalación.
